# Telefunken

Telefunken is a popular card game in South America. It is a type of contract rummy game and more information on the rules can be found here:
http://www.pagat.com/rummy/telefunken.html

# Developed with AI

Developed locally using opencode and qwen3.6 with ollama.

# Peru Version 1

This version only needs 3 files to work.
- index.html
- games.js
- style.css

Host these together in a web server.
